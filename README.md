# StarCatch + Cloudflare Tunnel (Windows)

1. Распакуйте папку куда угодно.
2. Дважды щёлкните **start.bat**. При первом запуске он сам вызовет install.bat
   (поставит Node.js через winget, зависимости и cloudflared).
3. В окне появится ссылка вида https://xxxx.trycloudflare.com: она скопирована в буфер.
   Отправьте её друзьям, они заходят и играют, ничего ставить не надо.
4. Чтобы остановить, нажмите любую клавишу в окне start.bat.

Заметки
- Ссылка меняется при каждом запуске (бесплатный quick tunnel, аккаунт не нужен).
- Постоянный адрес: создайте именованный туннель в Cloudflare Zero Trust и запускайте
  `cloudflared.exe tunnel run --token ВАШ_ТОКЕН` вместо строки с `--url`.
- Если Node.js только что установился, закройте окно и запустите start.bat снова.
- Порт по умолчанию 3000, меняется переменной PORT в start.bat.
